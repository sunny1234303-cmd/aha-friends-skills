# campaign-report-automation 스킬

## 상황

매주/매월 반복되는 광고 캠페인 성과 리포트 작성. 원본 데이터를 손으로 정리하고 지난 기간과 비교해 인사이트를 뽑는 데 시간이 오래 걸리는 업무를 자동화한다.

## 진행 순서

1. 광고 플랫폼(메타·구글 등)에서 원본 성과 데이터 내보내기
2. 지표 정제 및 이상치 체크
3. 전주 대비 변화와 원인 후보 자동 요약
4. 슬라이드/문서 형식 리포트로 정리

## 결과물

전주 대비 변화가 정리된 리포트 초안. 실제 수치·클라이언트명은 각자 업무 상황에 맞게 채워 넣는다.

## 참고

이 저장소를 포크한 뒤, 본인의 실제 리포트 양식·플랫폼(카페24, 네이버 광고 등)에 맞게 단계를 수정해서 쓰면 된다.
