## 2. 브랜드별 구조 흐름 (섹션별 분해)

### 2-1. 에스네이처 — 아쿠아 스쿠알란 수분크림

```
실시간 랭킹 인증 → 리뷰 소셜프루프 → 제품 비주얼+증정세트 → 효능 POINT1(피지조절·모공)
→ 효능 POINT2(4계절 대응, 4대 효능 아이콘) → 임상 그래프(속보습 +8.58%)
→ Q&A형 성분 설명(스쿠알란 150,000ppm) → 발림성/사용감 → 사용법
→ 라인업 크로스셀(6종) → 어워드 82관왕 배지월(클로징)
```

| 섹션 | 위치 | 핵심 메시지 | 설득 기법 |
|---|---|---|---|
| 랭킹 후킹 | 0~5% | "올리브영 전체 카테고리 1위" | 실제 올리브영 랭킹 페이지 스크린샷을 그대로 삽입 — 제3자 검증처럼 보이게 함 |
| 소셜프루프 | 5~8% | 리뷰 4.8점, 28,889건 | 실사용 후기 3개 인용(아이디 마스킹) |
| 제품 소개 | 8~15% | "수분천재크림", 기획세트 구성 | 제품 비주얼 + 증정 구성 명시 |
| POINT 1 | 15~25% | 번들거림 아닌 피지조절+모공쫀쫀 | Before/After가 아니라 "오해 바로잡기" 화법(번들거림 아닌 광채) |
| POINT 2 | 25~35% | 4계절 대응, 수분·모공·피지·진정 4효능 | 픽토그램 아이콘 4개로 효능 한눈에 요약 |
| 임상 증명 | 35~50% | 속보습 개선 +8.58% | 막대그래프 + 임상 대상자·시험기관 각주로 신뢰도 보강 |
| 성분 설명 | 50~65% | "왜 수분천재인가" 스쿠알란 150,000ppm | Q&A 포맷으로 궁금증→답변 구조, 원료(올리브) 이미지로 자연 유래 강조 |
| 사용감 증명 | 65~75% | 4계절 내내 수분·피지 케어 | 손등 발림성 사진 2연속 |
| 사용법/라인업 | 75~90% | "수분천재템" 크로스셀 | 6개 제품 아이콘 그리드 + 각 제품 한 줄 소개 |
| 클로징 | 90~100% | "82관왕" | 전 제품 라인업 사진 위에 인증 배지 수십 개를 겹쳐 배치 — 압도적 물량으로 마무리 |

### 2-2. 셀리맥스 — 트라넥삼산 잡티크림

```
입점 프로모션 배너 → 한정 할인가 강조 → 인플루언서 PICK 배지
→ 성분 순도(TXA 99%) → 2주 만족도 설문(100%) → 임상 모델컷(멜라닌케어)
→ 피부저자극 테스트(자극지수 0.00) → 용기 소개 → 사용감(TEXTURE)
→ HOW TO USE(개발자 추천) → 100% 환불 보장 → 브랜드 스토리(클로징)
```

| 섹션 | 위치 | 핵심 메시지 | 설득 기법 |
|---|---|---|---|
| 프로모션 후킹 | 0~5% | "올리브영 오프라인 매장 입점", 7월 한정 | 제품 효능이 아니라 유통 확대 소식으로 시작 — 신뢰도(매장 입점=검증됨) 프레이밍 |
| 할인가 강조 | 5~10% | 35,000→21,900원 | 1차/2차 할인가 병기로 "지금이 최저가"처럼 보이게 함 |
| 배지 | 10~12% | "아이돌 PICK", 나이아신아마이드 5%+트라넥삼산 5% | 셀럽 연상 배지 삽입 |
| 성분 강조 | 12~20% | 순도 99% TXA | 확대경 비주얼로 "고순도"를 시각적으로 은유 |
| 만족도 설문 | 20~35% | 2주 사용 만족도 100% (7개 항목) | 항목별 100% 반복 나열 — 실측 데이터가 아닌 주관적 설문임을 각주에만 작게 표기 |
| 임상 모델컷 | 35~40% | "고함량 멜라닌케어로 칙칙한 흔적까지" | 클로즈업 모델 사진으로 정서적 신뢰 보강 |
| 안전성 | 40~50% | 피부 저자극 테스트 완료, 자극지수 0.00 | 표 형식 인증 정보 + 배지 |
| 용기/사용감 | 50~65% | 위생적 튜브, 낮에도 끈적임 없음 | 사용성/제형 2개 카드로 정리 |
| 사용법 | 65~75% | "제품 개발자 추천" 활용법 (얼굴+바디) | "개발자 추천"이라는 개인화된 화자로 신뢰 부여 |
| 리스크 리버설 | 75~85% | 30일 내 100% 환불 | 구매 망설임을 정면으로 해소하는 명시적 보장 문구 |
| 브랜드 스토리 | 85~100% | "나비존 피부 문제"를 연구해 개발 | 무드보드형 이미지 + 개발 서사로 감성적 클로징, 라인 세럼 교차판매 슬쩍 언급 |

### 2-3. 브링그린 — 티트리 시카 수딩크림 플러스

```
사은품 프로모션 → 코미디 밈 후킹(개그맨 3인) → 여름철 문제 제기
→ 누적판매량+실사용 후기 → 사용만족도(수분감/흡수력/진정감)
→ 여름철 문제 재확인→해결책 제시 → 사용법(크림팩/화잘먹) → 비건 인증
→ 라인업 3종 교차판매(클로징)
```

| 섹션 | 위치 | 핵심 메시지 | 설득 기법 |
|---|---|---|---|
| 사은품 후킹 | 0~10% | 4만원 이상 구매 시 파우치 100% 증정 | 제품 효능이 아니라 **사은품**으로 최상단을 시작 — 셋 중 유일하게 "혜택"이 첫인상 |
| 코미디 밈 | 10~18% | "번들번들 vs 들쑥날쑥", 개그맨 리액션 | 밈(meme) 포맷 카피 + 코미디언 모델로 부담 없는 공감대 형성, 클리니컬 톤과 정반대 |
| 문제 제기 | 18~25% | "더운 날씨에 번들번들 유분기", 수부지 여름철 생존템 | **계절을 카피에 직접 명시** (3사 중 유일) |
| 소셜프루프 | 25~35% | 누적판매량, 실사용 후기 3개 | "정착템"이라는 재구매 뉘앙스 단어 사용 |
| 만족도 | 35~45% | 수분감·흡수력·진정감 (수치 대신 원형 아이콘) | 구체적 %가 아니라 아이콘+모델 사진으로 "느낌" 전달 (셀리맥스의 수치 나열과 대조적) |
| 문제 재확인 | 45~55% | "여름철 피부열감, 과잉피지, 유분량" → "티트리 시카 크림 하나로 해결" | 문제→해결 화법을 상단(코미디)과 중단(진지)에서 두 번 반복 |
| 사용법 | 55~70% | 크림팩, 화장 전 케어 2가지 활용법 | 텍스처 클로즈업 사진 + 번호 매긴 팁 카드 |
| 인증 | 70~75% | 이브 비건 인증 | 배지 1개로 간결하게 처리 (셀리맥스만큼 인증을 안 쌓음) |
| 클로징/크로스셀 | 75~100% | "유분 잡고 수분 넣는 티트리 시카 라인" | 토너/패드/크림 3종을 각각 태그(#각질숙식 #수분충전 등)와 함께 나열 |

**읽어야 할 포인트**
- 세 브랜드 모두 **20~30명 안팎의 소규모 표본**이라는 공통점이 있음 — "수백 명 대상"처럼 과장해서 벤치마킹하지 말 것
- 에스네이처만 유일하게 **극민감 피부 대상(더마프로) + 일반 민감 피부 대상(엘리드) 시험을 이중으로** 갖고 있음 — 임상적 포지셔닝이 가장 두터움
- 셀리맥스·브링그린의 "만족도 100%"류 수치는 계측기가 아니라 **설문 응답 비율**임 — 그래프만 보면 임상 데이터처럼 보이지만 각주를 봐야 실체를 알 수 있음. 우리 상세페이지에서 이런 수치를 쓸 때도 어떤 근거인지 각주에 정직하게 밝히는 게 좋음(경쟁사도 다 그렇게 하고 있어 안 밝히면 오히려 눈에 띔)

## 5. 공통 패턴 (3개 브랜드 모두 사용)

1. **수치/증거를 상단 1/3 안에 배치** (랭킹, 순도, 만족도 등 종류는 다르지만 위치는 동일)
2. **실사용 후기 직접 인용**: 별점 + 아이디 뒷자리 마스킹(`***`) 형태로 신뢰도 확보
3. **성분/효능 설명 → 사용감 증명(발림성 사진) → 사용법 → 라인업 교차판매 → 인증/클로징** 순서의 뼈대는 거의 동일
4. **브랜드 로고 또는 라인업 이미지로 클로징**, 강매 문구 없이 깔끔하게 마무리

## 6. 차별화 포인트 (셋이 서로 다르게 승부하는 지점)

- **증거의 종류**: 에스네이처=계측 데이터(임상), 셀리맥스=설문 만족도(주관적 %), 브링그린=실사용 후기+코미디 공감
- **첫인상 소재**: 에스네이처=랭킹 데이터, 셀리맥스=유통망 확대 소식, 브링그린=사은품 프로모션 → 셋 다 "제품 효능"으로 바로 시작하지 않음
- **리스크 처리**: 셀리맥스만 "환불 보장"으로 구매 망설임을 정면 돌파. 나머지 둘은 안전성 인증(테스트 완료)으로 간접 방어
- **여름 시즌 언급 방식**: 브링그린만 "여름철 수부지/번들거림"을 카피에 두 번(코미디+진지) 반복 명시. 에스네이처는 "4계절" 문구로 두루뭉술하게, 셀리맥스는 계절 언급 없음

## 7. 여름 수분크림 신제품 상세페이지에 적용할 점

**따라할 것**
- 상단 1/3 안에 수치 하나(판매량이든 만족도든 인증이든)는 반드시 넣는다 — 3개 전부 예외 없이 이 규칙을 따름
- "제품 효능"으로 바로 시작하지 말고, 랭킹/프로모션/사은품 등 **주의를 끄는 다른 소재로 먼저 후킹**한 뒤 효능 설명으로 넘어가는 구조가 3사 공통
- 계절 타겟팅을 하려면 브링그린처럼 **직접, 반복** 언급하는 게 효과적 (에스네이처식 "4계절" 두루뭉술 카피보다 임팩트가 큼)

**차별화 기회 (경쟁사가 약한 지점)**
- 셀리맥스 외 두 곳은 리스크 리버설(환불 보장 등) 장치가 없음 — 자신 있으면 이 부분에서 차별화 가능
- 세 브랜드 다 "여름철 실제 사용 환경"(땀, 자외선, 에어컨 실내외 온도차 등)에 대한 구체적 시나리오 묘사는 약함(브링그린도 "문제 제기"만 하고 상황 묘사까지는 안 들어감) — 상황 기반 스토리텔링으로 파고들 여지 있음

**우리는 다르게 할 것 (검토 필요)**
- 에스네이처식 임상 수치는 실제 자사 임상 데이터 없이 모방하지 말 것
- 브링그린의 코미디 톤은 브랜드 톤이 이미 정해져 있다면 억지로 따라 하지 말 것 — 톤은 일관성이 신뢰도에 더 중요
