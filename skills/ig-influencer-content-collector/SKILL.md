# ig-influencer-content-collector 스킬

## 상황

인플루언서 협업이 늘어날수록 2차 활용을 위해 원본 사진을 하나씩 찾아 저장하는 일이 병목이 됐다. 별도 프로그램 설치나 로그인 절차 없이, 실제로 일하는 화면(인스타그램 게시물 페이지)에서 바로 실행할 수 있어야 한다는 게 기준이었다. 그래서 서버 없이 브라우저에서 바로 동작하는 크롬 확장 프로그램 형태를 선택했다.

## 진행 순서

1. 협업 인플루언서의 게시물 페이지에서 크롬 확장 프로그램 아이콘 실행
2. 확장 프로그램이 페이지 소스에서 원본 해상도 이미지·영상 URL을 자동 탐지
3. 탐지된 원본 파일을 화질 손실 없이 순서대로 다운로드
4. 인플루언서명·캠페인명 기준으로 폴더를 자동 생성해 다운로드 파일 분류 저장
5. 파일명을 게시물 날짜·순번 규칙에 맞게 일괄 리네이밍
6. 완료 알림으로 저장된 파일 수 확인

## 결과물

인플루언서·캠페인별로 분류된 원본 해상도 이미지 폴더. 수동으로 하나씩 찾아 저장하던 작업(약 4일)을 3시간 수준으로 줄였다.

## 참고

이 저장소를 포크한 뒤, 본인이 다루는 SNS 플랫폼(인스타그램 외 다른 채널 포함)과 파일링 규칙에 맞게 단계를 수정해서 쓰면 된다. 크롬 확장 프로그램 코드 자체는 각자 개발 환경에 맞춰 새로 구현이 필요하다 — 이 문서는 워크플로우 설계를 공유하는 용도다.
