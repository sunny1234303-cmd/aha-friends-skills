# ig-influencer-content-collector 스킬

## 상황

인플루언서 협업이 늘어날수록 2차 활용을 위해 원본 사진을 하나씩 찾아 저장하는 일이 병목이 됐다. 별도 프로그램 설치나 로그인 절차 없이, 실제로 일하는 화면(인스타그램 게시물 페이지)에서 바로 실행할 수 있어야 한다는 게 기준이었다. 그래서 서버 없이 브라우저에서 바로 동작하는 크롬 확장 프로그램(Manifest V3) 형태로 만들었다.

## 실제 구현 — `extension/` 폴더

이 폴더에는 실제로 동작하는 크롬 확장 프로그램 소스가 그대로 들어있다. 설치 방법은 `설치_사용_가이드.md` 참고.

### 주요 기능

1. **저장 버튼 자동 삽입**: `content.js`가 `MutationObserver`로 피드의 게시물을 감지해 이미지 우측 상단에 ↓ 버튼을 자동 삽입 (스크롤 중 새로 로드되는 게시물에도 적용)
2. **캐러셀 자동 전체 수집**: 버튼 클릭 시 "다음" 버튼을 자동으로 순차 클릭해 전체 슬라이드를 순회하며 수집 (최대 30슬라이드, 다국어 "다음" 버튼 인식)
3. **최고 해상도 추출**: `srcset` 속성을 파싱해 가장 큰 width의 URL을 선택, 없으면 `src`로 fallback. 프로필 사진 등은 자동 제외
4. **저해상도 확인 팝업**: 1000px 미만 이미지가 섞여 있으면 썸네일 미리보기와 함께 저장 여부를 확인
5. **자동 파일명 생성**: `계정아이디(번호).jpg` 형식, 채널별로 독립 카운팅하며 `chrome.storage.local`에 저장돼 브라우저 재시작 후에도 유지
6. **툴바 팝업**: 채널별 저장 현황 확인, 카운터 초기화

## 결과물

인플루언서·채널별로 자동 넘버링된 원본 해상도 이미지 파일. 수동으로 하나씩 찾아 저장하던 작업(약 16시간)을 3시간 수준으로 줄였다.

## 참고

이 저장소를 포크한 뒤 `extension/` 폴더를 그대로 크롬에 로드해서 쓸 수 있다. 다른 SNS 플랫폼(인스타그램 외)에 적용하려면 `content.js`의 DOM 선택자·해상도 추출 로직을 해당 사이트 구조에 맞게 수정하면 된다.
