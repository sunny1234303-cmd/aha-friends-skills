# Instagram Image Saver — 완전 초보자용 설치 & 사용 가이드

이 문서만 보고 따라 하면 누구나 설치부터 사용까지 끝낼 수 있도록 작성했습니다.
컴퓨터 용어를 잘 몰라도 괜찮습니다. 순서대로 그대로 따라 하세요.

---

## 0. 시작 전에 알아둘 것

- 이 확장 프로그램은 **크롬(Chrome) 브라우저에서만** 작동합니다. (사파리, 엣지, 웨일 등에서는 안 됨)
- 크롬이 없다면 먼저 설치하세요: https://www.google.com/chrome/
- "확장 프로그램"이란, 크롬에 기능을 추가해주는 작은 프로그램입니다. 우리는 스토어에서 받는 게 아니라, 받은 압축 파일을 풀어서 그 폴더를 직접 불러와 설치할 겁니다. (이런 방식을 "압축 해제된 확장 프로그램 로드"라고 부릅니다)
- **받은 `instagram-saver.zip` 파일의 압축을 먼저 풀어주세요.**
  - 압축 파일에서 마우스 오른쪽 버튼 클릭 → **"압축 풀기"**(또는 "여기에 압축 풀기") 선택
  - 바탕화면이나 문서 폴더처럼 나중에 다시 찾기 쉬운 곳에 풀어두는 것을 추천합니다.
  - 압축을 풀면 `instagram-saver`라는 이름의 폴더가 생깁니다. **이 폴더 위치를 기억해두세요.** (2단계에서 다시 찾아야 합니다)
  - 이 폴더를 나중에 삭제하거나 이름을 바꾸면 확장 프로그램이 작동을 멈추니, 설치 후에도 계속 보관해야 합니다.

---

## 1단계. 개발자 모드 켜기

1. 크롬 브라우저를 엽니다.
2. 주소창(맨 위 URL 입력하는 곳)을 클릭하고, 아래 주소를 정확히 입력한 뒤 Enter를 누릅니다.
   ```
   chrome://extensions
   ```
3. "확장 프로그램" 관리 화면이 열립니다.
4. 화면 **오른쪽 위**를 보면 **"개발자 모드"**라는 토글(스위치) 버튼이 있습니다.
5. 이 스위치를 클릭해서 **켜짐(파란색/초록색)** 상태로 만듭니다.
   - 켜면 화면 위쪽에 새로운 버튼들("압축해제된 확장 프로그램을 로드합니다", "압축" 등)이 나타납니다.

---

## 2단계. 확장 프로그램 불러오기(설치)

1. 방금 나타난 버튼 중 **"압축해제된 확장 프로그램을 로드합니다"** (영문이면 "Load unpacked")를 클릭합니다.
2. 폴더를 선택하는 창이 뜹니다.
3. **0단계에서 압축을 푼 `instagram-saver` 폴더**를 찾아 들어갑니다.
   - 예: 바탕화면에 압축을 풀었다면 `바탕화면 > instagram-saver`
4. **`instagram-saver` 폴더 자체를 선택**하고 "폴더 선택" 버튼을 누릅니다.
   - 주의: 폴더 안의 특정 파일이 아니라, **폴더 전체**를 선택해야 합니다.
5. 잠시 후 확장 프로그램 목록에 **"Instagram Image Saver"**가 나타나면 설치 성공입니다.

### 설치가 잘 됐는지 확인하는 방법
- 크롬 창 오른쪽 위, 주소창 옆에 퍼즐 조각 모양 아이콘(확장 프로그램 아이콘)을 클릭합니다.
- 목록에 "Instagram Image Saver"가 보이면 성공입니다.
- 아이콘을 항상 보이게 하고 싶다면, 이름 옆의 **핀(📌) 아이콘**을 눌러 고정하세요.

## 3단계. 인스타그램에서 사용하기

### 사진 저장하는 방법
1. 크롬에서 https://www.instagram.com 에 접속해 로그인합니다.
2. 피드(홈 화면)를 스크롤하며 게시물을 봅니다.
3. 게시물 사진의 **오른쪽 위 모서리**를 보면 작은 **↓ (아래 화살표) 버튼**이 새로 생긴 것을 볼 수 있습니다.
   - 이 버튼이 이 확장 프로그램이 추가한 "저장" 버튼입니다.
4. 저장하고 싶은 게시물에서 이 **↓ 버튼을 클릭**합니다.

### 사진이 여러 장인 게시물(캐러셀)인 경우
- 자동으로 "다음" 버튼을 눌러가며 모든 사진을 순서대로 찾아 모읍니다.
- 버튼 위에 지금 몇 번째 사진을 확인 중인지 숫자로 표시됩니다. (최대 30장까지 지원)
- 다 확인되면 자동으로 사진들이 한꺼번에 다운로드됩니다. 기다리기만 하면 됩니다.
- 사진들 사이에 있는 동영상은 자동으로 건너뛰고, 사진만 저장합니다.

### 화질이 낮은 사진이 섞여 있을 때
- 가로 1000px보다 작은(화질이 낮은) 사진이 포함되어 있으면, 화면에 작은 확인 창(팝업)이 뜹니다.
- 이 창에는 어떤 사진들이 저화질인지 작은 미리보기와 함께 보여줍니다.
- 세 가지 중 하나를 선택하세요.
  - **"예, 모두 저장"**: 저화질 사진도 포함해서 전부 저장
  - **"고해상도만 저장"**: 화질 좋은 사진만 저장하고 저화질은 건너뜀
  - **"취소"**: 아무것도 저장하지 않음

### 저장된 파일은 어디 있나요?
- 크롬의 **기본 다운로드 폴더**(보통 `내 PC > 다운로드` 또는 `Downloads` 폴더)에 저장됩니다.
- 파일 이름은 자동으로 이렇게 붙습니다: `계정아이디(번호).jpg`
  - 예: `marvel(1).jpg`, `marvel(2).jpg`, `marvel(3).jpg`
- 같은 계정에서 계속 저장하면 번호가 이어서 붙습니다. (`marvel(1)` 다음 저장은 `marvel(4)`처럼 이어짐)
- 계정이 다르면 번호도 각각 따로 셉니다. (marvel 계정과 nasa 계정의 번호는 서로 안 섞임)

## 4단계. 저장 현황 확인 & 초기화 (선택 사항)

1. 크롬 오른쪽 위, 확장 프로그램 목록에서 **"Instagram Image Saver" 아이콘을 클릭**합니다.
2. 작은 창이 뜨면서, 지금까지 계정별로 몇 장을 저장했는지 목록으로 보여줍니다.
3. 특정 계정의 번호(카운터)만 초기화하고 싶으면, 해당 줄의 **"초기화"** 버튼을 클릭합니다.
4. 전체를 한 번에 초기화하고 싶으면, 창 아래 **"전체 카운터 초기화"** 버튼을 클릭합니다.
   - 초기화하면 파일 번호가 다시 (1)부터 시작됩니다. 이미 저장된 사진 파일 자체가 지워지지는 않습니다. (숫자 세는 것만 초기화)

- **개인정보**: 이 확장 프로그램은 별도의 서버로 어떤 데이터도 전송하지 않습니다. 이미지 추출, 저장 카운터 등 모든 처리는 사용자의 브라우저 안에서만 이루어지며, 개인정보나 사용 기록을 수집·저장·전송하지 않습니다.
- 본인이 저장 권한이 있거나 개인 소장 목적의 콘텐츠에 한해 사용하시기 바랍니다.

## 자주 묻는 질문 (문제 해결)

**Q1. ↓ 버튼이 사진 위에 안 보여요.**
- 인스타그램 페이지를 새로고침(F5)해보세요.
- `chrome://extensions` 화면에서 "Instagram Image Saver"가 켜짐(파란 토글) 상태인지 확인하세요.
- 인스타그램이 화면 디자인을 바꾸는 경우 일시적으로 버튼이 안 뜰 수 있습니다.

**Q2. 클릭했는데 아무 반응이 없어요.**
- 인터넷 연결을 확인하고 페이지를 새로고침한 뒤 다시 시도하세요.
- 크롬 다운로드 설정에서 "다운로드 전 저장 위치 확인" 옵션이 켜져 있으면, 사진마다 저장 위치를 물어보는 창이 뜰 수 있습니다. 이 경우 크롬 설정 > 다운로드에서 해당 옵션을 꺼두면 자동 저장됩니다.

**Q3. 확장 프로그램을 삭제하고 싶어요.**
1. `chrome://extensions` 접속
2. "Instagram Image Saver" 카드에서 **"삭제"** 버튼 클릭

**Q4. 내용을 수정했는데 반영이 안 돼요. (개발/수정 시에만 해당)**
1. `chrome://extensions` 접속
2. "Instagram Image Saver" 카드의 **새로고침(🔄) 아이콘**을 클릭
3. 인스타그램 탭도 새로고침(F5)

**Q5. Firefox나 다른 브라우저에서도 되나요?**
- 안 됩니다. 크롬 전용으로 만들어졌습니다.
