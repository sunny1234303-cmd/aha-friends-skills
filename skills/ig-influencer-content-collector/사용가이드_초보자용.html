Instagram Image Saver — 사용가이드

완전 초보자용 설치 & 사용 가이드

이 문서만 보고 따라 하면 누구나 설치부터 사용까지 끝낼 수 있도록 작성했습니다. 컴퓨터 용어를 잘 몰라도 괜찮습니다. 순서대로 그대로 따라 하세요.

00시작 전에 알아둘 것

브라우저
이 확장 프로그램은 크롬(Chrome)에서만 작동합니다. 사파리·엣지·웨일 등에서는 사용할 수 없습니다. 크롬이 없다면 먼저 google.com/chrome에서 설치하세요.
확장 프로그램이란
크롬에 기능을 추가해주는 작은 프로그램입니다. 스토어에서 받는 방식이 아니라, 받은 압축 파일을 풀어서 그 폴더를 직접 불러오는 "압축 해제된 확장 프로그램 로드" 방식을 사용합니다.
압축 풀기
받은 instagram-saver.zip 파일에서 마우스 오른쪽 버튼 → "압축 풀기"를 선택하세요. 바탕화면처럼 나중에 찾기 쉬운 곳을 추천합니다. 압축을 풀면 instagram-saver 폴더가 생기며, 이 폴더 위치를 기억해야 합니다 (다음 단계에서 다시 찾습니다).
폴더 보관
설치 후에도 이 폴더를 삭제하거나 이름을 바꾸거나 다른 곳으로 옮기면 확장 프로그램이 작동을 멈춥니다. 계속 그 자리에 보관하세요.
아하모먼트 / GitHub에서 스킬을 받은 경우 — 별도의 instagram-saver.zip이 없습니다. 대신 이 스킬 폴더(ig-influencer-content-collector) 안의 extension 폴더가 아래 안내에서 말하는 instagram-saver 폴더에 해당합니다. 01·02단계에서 폴더를 고를 때 이 스킬 폴더 안의 extension 폴더를 선택하세요.

01개발자 모드 켜기

  1. 크롬 브라우저를 엽니다.
  2. 주소창을 클릭하고 다음 주소를 정확히 입력한 뒤 Enter를 누릅니다.
    chrome://extensions
  3. "확장 프로그램" 관리 화면이 열립니다.
  4. 화면 오른쪽 위의 "개발자 모드" 토글(스위치)을 찾습니다.
  5. 스위치를 클릭해 켜짐 상태로 만듭니다. 켜면 화면 위쪽에 새 버튼들이 나타납니다.

02확장 프로그램 불러오기(설치)

  1. 새로 나타난 버튼 중 "압축해제된 확장 프로그램을 로드합니다"(영문: Load unpacked)를 클릭합니다.
  2. 폴더를 선택하는 창이 뜹니다.
  3. 00단계에서 압축을 푼 instagram-saver 폴더를 찾아 들어갑니다. (예: 바탕화면에 풀었다면 바탕화면 > instagram-saver)
  4. instagram-saver 폴더 자체를 선택하고 "폴더 선택"을 누릅니다. 폴더 안의 특정 파일이 아니라 폴더 전체를 선택해야 합니다.
  5. 확장 프로그램 목록에 "Instagram Image Saver"가 나타나면 설치 성공입니다.
설치 확인하는 법 — 크롬 오른쪽 위 퍼즐 조각 아이콘을 클릭해 목록에 "Instagram Image Saver"가 보이는지 확인하세요. 이름 옆 핀(📌) 아이콘을 누르면 항상 보이도록 고정할 수 있습니다.

03인스타그램에서 사용하기

사진 저장하는 방법

  1. 크롬에서 instagram.com에 접속해 로그인합니다.
  2. 피드(홈 화면)를 스크롤하며 게시물을 봅니다.
  3. 게시물 사진의 오른쪽 위 모서리에 새로 생긴 작은 ↓ 버튼을 확인합니다.
  4. 저장하고 싶은 게시물에서 이 ↓ 버튼을 클릭합니다.

사진이 여러 장인 게시물(캐러셀)인 경우

자동 순회
"다음" 버튼을 자동으로 눌러가며 모든 사진을 순서대로 찾아 모읍니다. 최대 30장까지 지원하며, 버튼 위에 진행 상황이 숫자로 표시됩니다.
일괄 다운로드
모든 슬라이드 확인이 끝나면 자동으로 사진들이 한꺼번에 다운로드됩니다. 기다리기만 하면 됩니다.
동영상 처리
사진들 사이에 동영상이 있으면 자동으로 건너뛰고 사진만 저장합니다.

화질이 낮은 사진이 섞여 있을 때

가로 1000px보다 작은 사진이 포함되어 있으면 화면에 확인 팝업이 뜨고, 저화질 사진들을 작은 미리보기와 함께 보여줍니다. 아래 세 가지 중 하나를 선택하세요.

예, 모두 저장
저화질 사진도 포함해서 전부 저장
고해상도만 저장
화질 좋은 사진만 저장하고 저화질은 건너뜀
취소
아무것도 저장하지 않음

저장된 파일은 어디 있나요?

저장 위치
크롬의 기본 다운로드 폴더 (보통 내 PC > 다운로드)
파일 이름 규칙
형식: 계정아이디(번호).jpg — 예: marvel(1).jpg, marvel(2).jpg
번호 규칙
같은 계정은 번호가 이어서 붙고, 계정이 다르면 번호도 각각 따로 셉니다.

04저장 현황 확인 & 초기화 (선택 사항)

  1. 크롬 오른쪽 위, 확장 프로그램 목록에서 "Instagram Image Saver" 아이콘을 클릭합니다.
  2. 계정별로 지금까지 몇 장을 저장했는지 목록으로 보여주는 작은 창이 뜹니다.
  3. 특정 계정의 번호만 초기화하려면 해당 줄의 "초기화" 버튼을 클릭합니다.
  4. 전체를 한 번에 초기화하려면 창 아래 "전체 카운터 초기화" 버튼을 클릭합니다.
초기화하면 파일 번호가 다시 (1)부터 시작됩니다. 이미 저장된 사진 파일 자체가 지워지지는 않습니다 — 숫자를 세는 카운터만 초기화됩니다.

⚠️ 저작권 및 개인정보 안내

본 프로그램은 바이브코딩(AI 활용 개발)으로 제작되었으며, 별도의 보증 없이 있는 그대로("as-is") 제공됩니다.
  • 저작권 — 이 도구로 저장한 이미지의 저작권은 원저작자(게시물 작성자)에게 있습니다. 개인적으로 감상하는 목적을 벗어나 원저작자 동의 없이 재게시·배포·상업적으로 이용하는 것은 저작권법 및 인스타그램 이용약관 위반에 해당할 수 있습니다.
  • 책임 — 이 도구의 사용 및 저장한 콘텐츠의 활용으로 인해 발생하는 모든 법적 책임은 사용자 본인에게 있으며, 제작자는 이에 대해 책임지지 않습니다.
  • 개인정보 — 이 확장 프로그램은 별도의 서버로 어떤 데이터도 전송하지 않습니다. 이미지 추출, 저장 카운터 등 모든 처리는 사용자의 브라우저 안에서만 이루어지며, 개인정보나 사용 기록을 수집·저장·전송하지 않습니다.
  • 본인이 저장 권한이 있거나 개인 소장 목적의 콘텐츠에 한해 사용하시기 바랍니다.

자주 묻는 질문

Q1↓ 버튼이 사진 위에 안 보여요.
  • 인스타그램 페이지를 새로고침(F5)해보세요.
  • chrome://extensions에서 "Instagram Image Saver"가 켜짐 상태인지 확인하세요.
  • 인스타그램이 화면 디자인을 바꾸는 경우 일시적으로 버튼이 안 뜰 수 있습니다.
Q2클릭했는데 아무 반응이 없어요.
  • 인터넷 연결을 확인하고 페이지를 새로고침한 뒤 다시 시도하세요.
  • 크롬 설정 > 다운로드에서 "다운로드 전 저장 위치 확인" 옵션이 켜져 있으면 사진마다 저장 위치를 물어봅니다. 꺼두면 자동 저장됩니다.
Q3확장 프로그램을 삭제하고 싶어요.
  1. chrome://extensions 접속
  2. "Instagram Image Saver" 카드에서 "삭제" 클릭
Q4내용을 수정했는데 반영이 안 돼요. (개발/수정 시에만 해당)
  1. chrome://extensions 접속
  2. "Instagram Image Saver" 카드의 새로고침(🔄) 아이콘 클릭
  3. 인스타그램 탭도 새로고침(F5)
Q5Firefox나 다른 브라우저에서도 되나요?
안 됩니다. 크롬 전용으로 만들어졌습니다.
