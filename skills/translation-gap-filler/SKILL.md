# translation-gap-filler 스킬

## 상황

Chrome 자동 번역은 스크롤·클릭으로 새로 나타나는 콘텐츠(무한스크롤, SPA 라우팅), iframe 내부 텍스트, `lang` 속성이 잘못 지정된 페이지를 놓친다. 유튜브 영어 강좌도 마찬가지로 자동 번역 대상이 아니다. 매번 다시 번역 버튼을 누르거나 부분 번역된 페이지를 손으로 확인하는 대신, 놓친 부분만 자동으로 채워주는 크롬 확장 프로그램(Manifest V3)으로 만들었다.

## 실제 구현 — `extension/` 폴더

이 폴더에는 실제로 동작하는 크롬 확장 프로그램 소스가 그대로 들어있다. 설치 방법은 `설치_사용_가이드.md` 참고.

일반 사용자는 저장소 전체를 받을 필요 없이 이 폴더에 함께 커밋된 `translation-gap-filler-extension.zip` 한 개만 내려받아, 영구 보관할 위치에 압축을 풀고 그 폴더를 "압축 해제된 확장 프로그램"으로 로드하면 된다. (zip 재생성: `extension/` 내용을 `translation-gap-filler-extension/` 폴더에 담아 압축)

### 주요 기능

1. **자동 시작**: 버튼 클릭 없이 페이지를 열면 바로 번역 시작, 화면 우측 상단에 "번역이가 번역 중..." 토스트로 알려줌
2. **lang 속성 무시**: 페이지가 선언한 `lang` 태그를 신뢰하지 않고 텍스트 조각 단위로 언어를 자동 감지(`sl=auto`)해서 번역 대상을 판단
3. **동적 콘텐츠 자동 감지**: `MutationObserver`로 스크롤·클릭 이후 새로 추가되는 DOM 노드를 감지해 실시간 번역
4. **iframe 커버**: `manifest.json`의 `all_frames: true`로 광고·위젯 iframe 내부 텍스트까지 번역
5. **유튜브 자막 자동 켜기**: `/watch`, `/embed/*` 페이지에서 꺼져 있는 CC 자막을 자동으로 켬 — 자막도 일반 DOM 텍스트라 기존 번역 로직이 그대로 처리 (라이브 스트리밍처럼 같은 노드가 실시간으로 계속 바뀌는 자막은 범위 밖)
6. **속도 최적화**: 텍스트를 청크(12개) 단위로 나눠 동시에 번역 요청 → 큰 페이지도 화면에 순차적으로 빠르게 채워짐. `background.js`의 전역 세마포어로 동시 요청 수(10개)를 제한해 번역 API 차단 위험도 관리
7. **캐싱**: 동일 문자열은 재번역하지 않고 캐시에서 즉시 반환

### 번역 엔진

비공식 Google 번역 엔드포인트(`translate.googleapis.com`)를 사용 — 무료, API 키 불필요. 페이지 텍스트가 이 엔드포인트로 전송되므로 사내 시스템·로그인 필요 페이지에서는 주의가 필요하다.

## 결과물

Chrome 기본 번역이 놓친 부분(동적 콘텐츠, iframe, 유튜브 자막)까지 자동으로 채워진 페이지. 별도 서버나 계정 없이 브라우저에 설치만 하면 바로 동작한다.

## 참고

이 저장소를 포크한 뒤 `extension/` 폴더(또는 배포용 `translation-gap-filler-extension.zip`)를 그대로 크롬에 로드해서 쓸 수 있다. 번역 엔진을 무료 MT 대신 LLM(자연스러운 문장, 마케팅 카피 톤 보존)으로 바꾸려면 `background.js`의 `translateOne` 함수만 API 호출로 교체하면 된다.
