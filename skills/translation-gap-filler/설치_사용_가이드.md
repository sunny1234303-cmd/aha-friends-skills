# 번역이 — 완전 초보자용 설치 & 사용 가이드

이 문서만 보고 따라 하면 누구나 설치부터 사용까지 끝낼 수 있도록 작성했습니다.
컴퓨터 용어를 잘 몰라도 괜찮습니다. 순서대로 그대로 따라 하세요.

---

## 0. 시작 전에 알아둘 것

- 이 확장 프로그램은 **크롬(Chrome) 브라우저에서만** 작동합니다. (사파리, 엣지, 웨일 등에서는 안 됨)
- 크롬이 없다면 먼저 설치하세요: https://www.google.com/chrome/
- "확장 프로그램"이란, 크롬에 기능을 추가해주는 작은 프로그램입니다. 우리는 스토어에서 받는 게 아니라, 받은 압축 파일을 풀어서 그 폴더를 직접 불러와 설치할 겁니다. (이런 방식을 "압축 해제된 확장 프로그램 로드"라고 부릅니다)
- 이 저장소를 다운로드했다면 `skills/translation-gap-filler/extension` 폴더가 설치 대상입니다. **이 폴더 위치를 기억해두세요.** (2단계에서 다시 찾아야 합니다)
- 이 폴더를 나중에 삭제하거나 이름을 바꾸면 확장 프로그램이 작동을 멈추니, 설치 후에도 계속 보관해야 합니다.

---

## 1단계. 개발자 모드 켜기

1. 크롬 브라우저를 엽니다.
2. 주소창(맨 위 URL 입력하는 곳)을 클릭하고, 아래 주소를 정확히 입력한 뒤 Enter를 누릅니다.
   ```
   chrome://extensions
   ```
3. "확장 프로그램" 관리 화면이 열립니다.
4. 화면 **오른쪽 위**를 보면 **"개발자 모드"**라는 토글(스위치) 버튼이 있습니다.
5. 이 스위치를 클릭해서 **켜짐(파란색/초록색)** 상태로 만듭니다.
   - 켜면 화면 위쪽에 새로운 버튼들("압축해제된 확장 프로그램을 로드합니다" 등)이 나타납니다.

---

## 2단계. 확장 프로그램 불러오기(설치)

1. 방금 나타난 버튼 중 **"압축해제된 확장 프로그램을 로드합니다"** (영문이면 "Load unpacked")를 클릭합니다.
2. 폴더를 선택하는 창이 뜹니다.
3. **0단계에서 확인한 `extension` 폴더**를 찾아 들어갑니다.
   - 예: `translation-gap-filler > extension`
4. **`extension` 폴더 자체를 선택**하고 "폴더 선택" 버튼을 누릅니다.
   - 주의: 폴더 안의 특정 파일이 아니라, **폴더 전체**를 선택해야 합니다.
5. 잠시 후 확장 프로그램 목록에 **"번역이"**가 나타나면 설치 성공입니다.

### 설치가 잘 됐는지 확인하는 방법
- 크롬 창 오른쪽 위, 주소창 옆에 퍼즐 조각 모양 아이콘(확장 프로그램 아이콘)을 클릭합니다.
- 목록에 "번역이"가 보이면 성공입니다.
- 아이콘을 항상 보이게 하고 싶다면, 이름 옆의 **핀(📌) 아이콘**을 눌러 고정하세요.

---

## 3단계. 사용하기

### 웹페이지에서
1. 아무 영어 페이지나 열어보세요. (예: 부분 번역만 되던 사이트)
2. 페이지가 열리면 **버튼을 누르지 않아도 자동으로 번역이 시작**됩니다.
3. 화면 **오른쪽 위**에 "번역이가 번역 중..." 이라는 작은 알림(토스트)이 잠깐 나타났다 사라집니다.
4. 스크롤을 내리거나 클릭해서 새로운 내용이 나타나도, 그 내용도 자동으로 번역됩니다.
5. 번역을 끄고 싶으면, 크롬 오른쪽 위 확장 프로그램 아이콘을 클릭 → 팝업에서 **"번역 중지"** 버튼을 누르세요.
   - 또는 단축키 `Ctrl+Shift+Y` (맥은 `⌘⇧Y`)를 눌러도 켜고 끌 수 있습니다.
   - 끄고 켠 상태는 페이지를 새로고침하면 초기화됩니다 (새 페이지를 열면 다시 자동으로 켜짐).

### 유튜브 강좌에서
1. 영어로 된 유튜브 영상(자막이 있는 강좌 등)을 엽니다.
2. 자막(CC)이 꺼져 있어도 **자동으로 켜집니다.**
3. 자막에 나오는 영어 문장이 한국어로 바뀌어 화면에 나타납니다.
4. 다른 영상으로 넘어가도 자동으로 다시 자막을 켜고 번역합니다.

> **주의**: 이 기능은 자막이 있는 영상에서만 동작합니다. 자막 자체가 없는 영상(자동 생성 자막도 없는 경우)은 번역할 원문이 없어서 작동하지 않습니다. 또한 실시간 라이브 방송의 자막처럼 계속 바뀌는 텍스트는 지원 범위 밖입니다.

## ⚠️ 이용 안내

본 프로그램은 **바이브코딩(AI 활용 개발)**으로 제작되었으며, 별도의 보증 없이 있는 그대로("as-is") 제공됩니다.

- **번역 방식**: 페이지의 텍스트를 비공식 Google 번역 서비스로 전송해 번역 결과를 받아옵니다. 사내 시스템, 로그인 후 보이는 민감한 페이지에서는 사용에 주의하세요.
- **책임**: 번역 결과의 정확성은 보장되지 않으며, 이 도구의 사용으로 발생하는 문제에 대해 제작자는 책임지지 않습니다.
- **개인정보**: 이 확장 프로그램 자체는 사용 기록이나 개인정보를 별도로 수집·저장하지 않습니다. 다만 번역을 위해 페이지의 텍스트 내용이 번역 서비스로 전송됩니다.

## 자주 묻는 질문 (문제 해결)

**Q1. 번역이 아예 안 돼요.**
- `chrome://extensions` 화면에서 "번역이"가 켜짐(파란 토글) 상태인지 확인하세요.
- 확장 프로그램을 새로 설치하기 전에 이미 열려있던 탭에는 적용되지 않습니다. 그 탭을 새로고침(F5 또는 ⌘R)하세요.

**Q2. 이미 한국어로 된 부분까지 이상하게 바뀌어요.**
- 원래 한국어가 포함된 문장은 건너뛰도록 만들어져 있습니다. 만약 이런 일이 보이면 어떤 페이지·문장이었는지 기록해두면 개선에 도움이 됩니다.

**Q3. 유튜브 자막이 자동으로 안 켜져요.**
- 그 영상에 자막 트랙 자체가 없을 수 있습니다. 유튜브 플레이어의 CC 아이콘을 직접 눌러 "자막 사용 불가"라고 뜨는지 확인해보세요.
- 유튜브가 화면 구조를 바꾸면 일시적으로 안 될 수 있습니다.

**Q4. 확장 프로그램을 삭제하고 싶어요.**
1. `chrome://extensions` 접속
2. "번역이" 카드에서 **"삭제"** 버튼 클릭

**Q5. 내용을 수정했는데 반영이 안 돼요. (개발/수정 시에만 해당)**
1. `chrome://extensions` 접속
2. "번역이" 카드의 **새로고침(🔄) 아이콘**을 클릭
3. 사용 중이던 탭도 새로고침(F5)

**Q6. Firefox나 다른 브라우저에서도 되나요?**
- 안 됩니다. 크롬 전용으로 만들어졌습니다.
