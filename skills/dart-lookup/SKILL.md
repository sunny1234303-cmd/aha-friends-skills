# dart-lookup 스킬

**Claude in Chrome 브라우저 툴(`mcp__claude-in-chrome__*`)이 있는 세션에서만 가능하다.** 없으면 사용자에게 브라우저 확장 사용 세션에서 다시 요청하라고 안내한다.

## 상황

한국 상장사의 재무 상태를 확인하고 싶을 때, 요약 통계 사이트가 아니라 DART 사업보고서 원문에서 직접 수치를 읽고 싶은 경우. 여기에 더해 동종업계와 비교했을 때 이 회사가 어디쯤 있는지, 해외 시장 대비 국내 시장에서 아직 확장할 여지가 있는지까지 참고용으로 궁금할 때 쓴다.

**주의**: 목표주가 산출이나 매수/보유/매도 같은 공식 투자의견은 내지 않는다. 재무 추세와 동종업계 대비 위치를 근거로 한 "시사점" 수준까지만 제시하고, 결과에 투자 자문이 아닌 참고용 분석이라는 점을 항상 명시한다.

## 데이터 검증 원칙 (필수, 모든 단계에 적용)

- **DART 사업보고서에서 직접 스크린샷으로 읽은 수치**(재무제표, 자산·부채, 지급수수료 등)는 원문 자체가 근거이므로 그대로 사용한다.
- **그 외 WebSearch로 얻는 모든 수치**(주가, 시가총액, PER, PBR, 경쟁사 매출성장률·영업이익률, 해외/국내 시장 규모·성장률 등)는 **서로 독립된 출처 2곳 이상에서 교차 확인한 뒤에만** 결과에 포함한다. 검색 1건으로 끝내지 말 것.
  - 두 출처의 수치가 일치하거나 합리적 오차 범위 내면 채택하고, 두 출처를 모두 각주로 표기
  - 두 출처가 서로 다르면 임의로 평균 내거나 하나를 골라 단정하지 말고 **"출처 간 상충 (A사이트: X / B사이트: Y)"**으로 그대로 병기
  - 신뢰할 만한 두 번째 출처를 못 찾았으면 그 항목은 보고서에 넣지 말고 **"확인 불가(단일 출처만 확인됨)"**로 명시
  - 검색 결과 자체가 없거나 출처 불명(개인 블로그, 커뮤니티 글 등)뿐이면 해당 항목을 통째로 생략하고 사용자에게 어떤 항목을 왜 뺐는지 밝힐 것
- **절대 수치를 그럴듯하게 추정하거나 기억에 의존해 채우지 않는다.** 확인되지 않은 숫자를 만들어내는 것보다 "확인 불가"라고 쓰는 쪽이 항상 낫다.
- 출처는 매체명을 구체적으로 표기한다 (예: 네이버페이 증권, 한국거래소 KIND, KOTRA, Statista, 업종별 협회 통계 등). 1차 기관·공신력 있는 매체를 개인 블로그·요약 사이트보다 우선한다.
- 이 원칙은 아래 진행 순서 8번(동종업계 비교), 10번(해외/국내 시장 현황) 단계 전체에 적용된다.

## 사용법

```
회사명만 주면 재무 요약 + 동종업계 비교 + 시장 확장 분석까지 자동으로 수행한다.
지급수수료/로열티 세부내역이 필요하면 "지급수수료도 확인해줘"처럼 요청에 함께 명시한다.
```

인자로 회사명을 받지 않았으면 "어떤 회사를 조회할까요?"라고 먼저 물어볼 것.

## 진행 순서

1. **탭 준비**: `tabs_context_mcp`(createIfEmpty: true)로 탭 확보 → `navigate`로 `https://dart.fss.or.kr/` 이동
2. **회사 검색**: 최상단 "공시통합검색" 입력창을 클릭 → **1초 대기 후** 회사명 타이핑 (클릭 직후 바로 타이핑하면 입력이 씹히는 경우가 있음). 자동완성 드롭다운에서 정확히 일치하는 회사명 선택 (계열사인 "OO홀딩스", "OO인베스트먼트" 등과 혼동 주의) → 검색 버튼 클릭
   - **주의**: 페이지 중간의 "정기공시 항목별 검색" 박스는 쓰지 말 것 — 자동완성 클릭 시 폼 전체가 리셋되는 버그가 있어 반복 실패한다. 반드시 최상단 "공시통합검색" 박스만 사용.
3. **정기공시 필터링**: 검색 결과 페이지(`dsab007/main.do`)에서 "정기공시" 체크박스 체크 → 검색. 목록에서 가장 최근 "사업보고서" 행 확인
4. **rcpNo 추출 후 직접 이동**: 사업보고서 링크를 클릭하지 말 것 — DART가 새 브라우저 창으로 열려고 하는데 이 창은 MCP 탭 그룹에 잡히지 않아 보이지 않게 된다. 대신 `find` 도구로 "사업보고서 공시뷰어 새창" 링크를 찾아 href에서 rcpNo(14자리 숫자)를 읽고, 같은 탭에서 `navigate`로 `https://dart.fss.or.kr/dsaf001/main.do?rcpNo={rcpNo}` 로 직접 이동
   - **주의**: 검색 과정 없이 rcpNo를 알아내서 세션 없이 곧바로 이 URL로 이동하면 "거부"라는 제목의 referer 차단 페이지가 뜬다. 반드시 2~3번 검색 흐름을 거친 뒤 같은 탭에서 navigate할 것. 거부 페이지가 뜨면 2번부터 다시 시도.
5. **섹션 이동**: 문서 뷰어의 좌측 "문서목차" 트리에서 `find`로 원하는 섹션을 찾아 클릭
   - 매출액/영업이익/영업이익률 → "2-2. 연결 포괄손익계산서" (개별재무제표는 "4-2. 포괄손익계산서") — 보통 당기/전기/전전기 3개년이 한 표에 나옴
   - 자산/부채 요약 → "1. 요약재무정보"
   - 지급수수료/로열티 등 판관비 세부 → "판매비와관리비 (연결)" — 회사마다 주석 번호가 다르므로 "판매비" 키워드로 목차에서 찾을 것. 이 항목은 로열티 외 유통수수료 등이 섞여 있어 순수 로열티만 분리되지 않는 경우가 많음. 라이선서와의 로열티 지급이 별도로 궁금하면 "특수관계자와의 거래" 주석도 확인
   - 클릭 후 화면이 안 바뀌면 좌표로 한 번 더 클릭
6. **데이터 읽기**: 반드시 `computer` 액션의 `screenshot`으로 시각적으로 읽을 것. **`get_page_text`는 이 페이지에서 좌측 목차만 반환하고 본문 표는 반환하지 않으므로 쓸모없다.**
7. **안정성 지표 확인**: "1. 요약재무정보" 섹션에서 자산총계·부채총계·자본총계(최근 3개년)를 함께 확인. 부채비율(부채총계/자본총계 × 100)을 계산해 재무 안정성 판단에 사용.
8. **동종업계 비교 데이터 수집 (WebSearch, 이중 검증 필수)**:
   - 조회 대상 회사와 같은 업종의 상장 경쟁사 2~3곳을 선정 (사업보고서의 "사업의 내용"에 언급된 경쟁사가 있으면 우선 활용, 없으면 웹검색으로 동일 업종 상장사 파악)
   - 각 회사(조회 대상 포함)의 **현재 주가, 시가총액, PER, PBR**을 서로 다른 출처(예: 네이버페이 증권 + 한국거래소 KIND, 또는 네이버페이 증권 + 다음금융) **2곳에서 각각 검색**해 대조
   - 경쟁사의 최근 매출성장률·영업이익률도 동일하게 2곳 이상에서 대조 (공시 원문·기업 IR 자료를 우선 신뢰)
   - 위 "데이터 검증 원칙"에 따라 일치하는 값만 채택, 상충하면 병기, 확인 안 되면 생략
   - 시장 데이터는 조회 시점 스냅샷이므로 결과에 조회 날짜를 명시할 것
9. **분석 종합**:
   - **성장성**: 매출액·영업이익 YoY 증감률, 3개년 추이의 방향(개선/둔화/역전)
   - **수익성**: 영업이익률 추이와 동종업계 평균 대비 위치
   - **안정성**: 부채비율 수준과 추이
   - **밸류에이션**: 조회 대상의 PER/PBR을 동종업계 평균과 비교해 상대적 고평가/저평가 시그널 언급
   - **시사점**: 위 네 가지를 종합해 강점·약점·주목할 리스크 요인을 bullet로 정리. 목표주가나 매수/보유/매도 의견은 제시하지 않는다.
10. **해외/국내 시장 현황 조사 (WebSearch, 항상 수행, 이중 검증 필수)**:
    - 사업보고서의 "매출 및 수주상황" 또는 "사업의 내용"에서 **지역별(국내/해외) 매출 비중**이 공시돼 있으면 확인 — 이 회사의 사업이 이미 해외에서도 통하는지 판단하는 1차 근거 (이건 DART 원문이므로 별도 웹검증 불필요)
    - **해외 시장** 규모·성장률(CAGR)·주요 트렌드는 서로 다른 출처(예: 글로벌 시장조사기관 리포트 + 업계 전문지·협회 통계) **2곳 이상**에서 검색해 대조
    - **한국 시장** 규모·성장률·경쟁 구도·포화도도 동일하게 2곳 이상에서 검색해 대조 (KOTRA, 산업통상자원부, 관련 협회, 증권사 산업 리포트 등 공신력 있는 출처 우선)
    - 위 "데이터 검증 원칙"에 따라 일치하는 값만 채택, 상충하면 병기(기준 연도·통화·범위 차이도 함께 표기), 확인 안 되면 생략
    - 두 시장의 성장 단계 차이(예: 해외는 성숙기, 국내는 아직 초기/성장기 등)를 검증된 수치를 근거로만 비교 — 추정으로 서술하지 말 것
11. **확장 전략 시사점**:
    - 해외 시장 대비 한국 시장이 상대적으로 저성장/포화 상태인지, 아직 성장 여지가 있는지 판단
    - 조회 대상 회사가 국내에서 점유율을 더 확대할 여지가 있는 세그먼트·채널·지역이 있는지
    - 해외 성공 사례(해당 업종의 해외 트렌드)를 국내에 적용할 수 있는 지점이 있는지
    - 3~5개 bullet로 정리하되, 근거가 부족하면 추측 대신 "확인되지 않음"으로 명시할 것

## 알려진 한계

- 문서 뷰어의 콘텐츠 영역은 마우스 휠 스크롤과 `Page_Down` 키가 반응하지 않는 경우가 많다. 표가 화면 아래로 잘려서 안 보이면 목차에서 더 세부 항목을 찾아보되, 일부 데이터를 놓칠 수 있음을 사용자에게 밝힐 것 — 억지로 우회하려 하지 말 것.
- 개별 회사의 순수 로열티율은 대부분 별도 공시되지 않는다. '지급수수료' 총액과 매출 대비 비중까지만 확인 가능하다는 점을 결과에 명시할 것.
- 동종업계 비교의 주가·PER·PBR은 웹검색 시점의 스냅샷이며, 조회 시점에 따라 달라진다. 목표주가 산출이나 공식 투자의견(매수/보유/매도)은 이 스킬의 범위가 아니며, 어디까지나 참고용 분석임을 결과 하단에 명시할 것.
- 해외/국내 시장 규모·성장률은 출처마다 기준(범위, 통화, 연도)이 다를 수 있다. "데이터 검증 원칙"에 따라 2곳 이상에서 대조하고, 상충하면 임의로 하나를 고르지 말고 그대로 병기한다. 사업보고서에 지역별 매출 비중이 아예 공시되지 않는 회사도 있으며, 이 경우 "지역별 매출 비중 미공시"로 명시하고 업종 단위의 해외/국내 시장 비교로 대체할 것.
- 이중 검증을 통과하지 못한 수치는 보고서에서 생략되므로, 최종 결과가 초기 설계보다 성글어 보일 수 있다. 이는 의도된 동작이다 — 항목이 비어 있거나 "확인 불가"로 표시된 것을 검색을 게을리한 결과로 오인해 추정치로 채우지 말 것.
