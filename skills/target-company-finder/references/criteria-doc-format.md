# 기준 문서 저장 포맷

Phase 0 인터뷰 결과를 정리하는 포맷. 실제 저장 위치는 사용자 워크스페이스 관례에 맞춘다(예: 개인 노트 폴더, 채용 준비 폴더 등) — 정해진 곳이 없으면 사용자에게 물어본다.

```markdown
# 타겟 기업 기준

## 목표
- 목표 직무/포지션: [사용자가 정의한 직무 타이틀 + 그 직무의 업무 범위 정의]
- 전체 방향: [예: 특정 스카웃 경로, 특정 산업 전환 등 — 있으면]

## 필수 조건 (하드 필터)
- [조건 1]
- [조건 2]
- ...
> 인터뷰 중간에 추가된 조건은 여기 계속 append한다. 새 조건이 추가되면 이미 판정한 후보들도 재검토 대상이라는 걸 문서 상단에 남긴다.

## 1. 업종 · 시장
- 관심 카테고리: [...]
- 성장성 기준: [...]
- 범위: [전통 대기업만 / 신생·투자유치 기업 포함 등]

## 2. 근무 환경 (공간)
- [...]
- (검증 불가 항목이 많다는 점을 문서에 명시)

## 3. 인적자원 / 피드백 문화
- [...]

## 4. 조직문화
- [...]

## 5. 업무 방식 / 직무 범위
- 목표 직무에 포함되는 것: [...]
- 목표 직무에서 명시적으로 제외하는 것: [...]
- (충돌이 있었다면) 충돌 해소 방식: [사용자가 어떻게 정의했는지 그대로 기록]
```

정정/업데이트가 생기면 날짜를 남기고 append 방식으로 이력을 쌓는다 (덮어쓰지 않는다) — 이후 리서치 결과를 재검토할 때 "이 조건이 언제 추가됐는지"가 판단 근거가 된다.
