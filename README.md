## 사용 방법

1. 위 표에서 쓰고 싶은 스킬의 저장소로 이동합니다.
2. 오른쪽 위 **Fork** 버튼으로 내 계정에 사본을 만듭니다.
3. 내 업무·환경에 맞게 `SKILL.md`를 수정해서 씁니다.

설치 방법은 각 저장소의 README에 있습니다.
