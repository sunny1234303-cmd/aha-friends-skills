# Aha Friends Skills

서로 다른 업계에서 일하는 사람들이 각자 업무에서 실제로 쓰는 AI 스킬을 모으고 업데이트하는 저장소입니다.

브랜드 마케터, 개발자, 자영업자, 교사, 물류 관리직 등 겹치지 않는 분야의 사람들이 모여, 자기 업무에 맞게 다듬은 [Claude Code Skill](https://docs.claude.com/en/docs/claude-code/skills)을 공유합니다. 완성된 라이브러리가 아니라 계속 채워지고 갱신되는 작업 공간입니다.

## 사용 방법

1. 이 저장소를 포크합니다.
2. `skills/` 아래 자신의 상황에 맞는 스킬 폴더를 추가하거나, 기존 스킬을 자신의 업무에 맞게 수정합니다.
3. 스킬 작성은 `skills/_template/SKILL.md`를 복사해서 시작하세요.

## 스킬 작성 규칙

- 폴더명은 스킬 이름과 동일한 kebab-case로 만듭니다 (예: `skills/my-skill/SKILL.md`).
- `SKILL.md` 상단 frontmatter에 `name`, `description`(트리거 문구 포함)을 반드시 채웁니다.
- 개인정보, 사내 기밀, 실제 고객 데이터는 포함하지 않습니다.
